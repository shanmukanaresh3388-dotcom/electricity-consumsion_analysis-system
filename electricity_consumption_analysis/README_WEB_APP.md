# Electricity Consumption Analysis — Web App

## Run locally
1. Install Python 3.10+.
2. In a terminal, enter this folder.
3. Run `python -m pip install -r requirements.txt`
4. Run `streamlit run app.py`
5. Open the local URL shown in the terminal (usually http://localhost:8501).

## Get a public URL
Push the project folder to a GitHub repository. In Streamlit Community Cloud, create a new app, select that repository, choose `app.py` as the main file, and deploy. The service will provide a public `https://...streamlit.app` URL. Do not share `localhost` as a public URL; it only works on your computer.
